# Geodata — русская адаптация документации

> Этот репозиторий основан на открытом проекте [GeodataTools/geodata](https://github.com/GeodataTools/geodata). Исходные авторы пакета указаны в `pyproject.toml`: Michael Davidson, William Honaker и Xiqiang Liu. Здесь сохранена русская адаптация описания и материалов для изучения проекта.

## О проекте

**Geodata** — Python-библиотека для сбора и предварительной обработки геопространственных данных. Она помогает приводить разнородные геоданные к формату, пригодному для дальнейшего анализа.

Проект работает с геопространственными и растровыми наборами данных и сохраняет совместимость с подходами библиотеки `atlite` для обработки метеорологических и энергетических данных.

## Возможности

- загрузка и предварительная обработка геопространственных данных;
- работа с временными рядами и растровыми наборами;
- подготовка данных для исследовательских и инженерных задач;
- примеры использования в Jupyter Notebook;
- пакетная структура с `src/`, тестами и документацией.

## Установка

Проект рассчитан на Python 3.9+.

Основные зависимости включают:

`numpy` · `scipy` · `pandas` · `xarray` · `dask` · `boto3` · `pyproj` · `rasterio` · `rioxarray` · `shapely` · `geopandas`

Подробные инструкции находятся в [`doc/general/packagesetup.md`](doc/general/packagesetup.md).
